# LunarisApp Tap

Homebrew formulae and casks maintained by LunarisApp.

## Installation

Install a formula directly:

```sh
brew install LunarisApp/tap/<formula>
```

Or tap the repository first:

```sh
brew tap LunarisApp/tap
brew install <formula>
```

For casks, use:

```sh
brew install --cask LunarisApp/tap/<cask>
```

In a `Brewfile`:

```ruby
tap "LunarisApp/tap"
brew "<formula>"
# cask "<cask>"
```

## Documentation

Run `brew help`, read `man brew`, or visit the
